# Orbit Slash 우주 BGM·설정·로그인·공유 디자인

## 목표

- 첫 진입부터 약 2분 길이의 긴박한 우주 전투 음악을 재생 시도하고 끊김 없이 반복한다.
- 브라우저 자동재생이 막히면 최초 포인터/키 입력에서 즉시 시작한다.
- Home 우측 상단에 설정 아이콘을 두고, 뽁뽁이의 설정 정보 구조를 참고한 게임 전용 패널을 연다.
- 설정에서 계정 상태, 언어, BGM, 효과음, 진동, 모션 줄이기, 앱 공유를 제공한다.
- 초대 코드 공유는 서버 원천·딥링크 계약이 준비될 때까지 `준비 중`으로 정확히 표시한다.

## 음악

- 원본 합성곡 `Orbit Siege`를 120초로 생성한다.
- 128 BPM, 256박으로 120초를 정확히 채우고 E 계열의 어두운 드론, 반복 아르페지오,
  저역 펄스, 경보성 노이즈를 겹친다.
- 시작/끝의 리듬·화성 주기를 맞추고 AAC/M4A로 배포한다. macOS 기본 변환기의
  Ogg Vorbis writer가 동작하지 않아 외부 도구 설치 없이 지원되는 AAC를 사용한다.
- HTMLAudioElement는 `loop=true`, BGM 설정값을 볼륨/재생 상태에 즉시 반영한다.
- WebAudio는 효과음용으로 유지한다. 자동재생 실패는 오류가 아니라 최초 사용자 제스처 대기로 처리한다.

## 설정 진입과 레이아웃

- 기존 Home 하단 `설정` 버튼은 제거하고, safe area 안 우측 상단에 96×96 논리 px 이상의
  기어 버튼을 둔다. 이모지 문자를 쓰지 않고 Pixi Graphics로 기어를 그린다.
- 설정은 전체 배경 위 중앙 카드 패널 구조다.
  1. 헤더: `설정`, 닫기/뒤로
  2. 계정 카드: 게스트/연결됨/로그인 중/오류 상태와 로그인 버튼
  3. 감각 설정: BGM, 효과음, 진동, 모션 줄이기
  4. 언어: 한국어/English
  5. 공유 카드: 앱 공유 버튼과 `초대 코드 공유 준비 중` 안내
- 360 CSS px 폭에서도 조작 영역은 48 CSS px 이상을 유지한다.
- 색은 기존 SSOT의 딥 네이비, 시안, 앰버, 슬레이트를 유지한다. 외부 검증 도구의
  파랑/분홍 팔레트는 기존 게임 시각 언어와 충돌하므로 채택하지 않는다.

## 로그인

- UI 상태는 `anonymous | loading | linked | error`로 분리한다.
- 제품 계층은 플랫폼 원시 키나 인증 코드를 받지 않고 서버가 정규화한 `internalUserId`만 받는다.
- 현재 Apps in Toss/Google Play 서버 세션 교환이 없는 환경에서는 게스트를 유지하고
  `현재 환경에서는 계정 연결을 사용할 수 없습니다`를 표시한다.
- 가짜 로그인 성공이나 raw Toss userKey 저장은 금지한다.

## 공유

- 플랫폼 경계 `ShareService`가 공유 기능을 소유한다.
- 순서: Apps in Toss `getTossShareLink` + `share` → `navigator.share` → 클립보드.
- Apps in Toss 딥링크는 `intoss://orbitslash`를 기본으로 사용한다. 정식 출시 전 테스트는
  private deployment scheme이 별도 필요하다는 점을 릴리즈 위험으로 남긴다.
- 현재 메시지는 앱 소개/링크만 포함한다. 초대 코드는 데이터 원천과 수신 라우팅이 준비된 뒤
  명시적으로 주입하는 `InviteDeepLinkBuilder`로만 연결한다. 기본 빌더는 비활성화한다.

## 검증 기준

- 음악 파일 재생 시간이 119.5~120.5초이고 2 MiB 이하이며 반복 재생 설정이 적용된다.
- 자동재생 성공 시 즉시, 실패 시 최초 제스처에서 BGM이 시작된다.
- BGM OFF, lifecycle pause, 설정 변경이 재생 상태에 반영된다.
- Home 우측 상단 설정 버튼과 설정 패널의 모든 액션이 실제 callback으로 연결된다.
- 로그인 상태와 공유 fallback 순서가 단위 테스트로 고정된다.
- ko/en 키 parity, 전체 Vitest, TypeScript, Vite build, asset budget가 통과한다.
