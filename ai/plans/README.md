# Plans

Keep recurring project artifacts at fixed canonical paths:

- `product-plan.md`
- `design-plan.md`
- `implementation-plan.md`
- `master-roadmap.md`

Use frontmatter with `version`, `status`, `updated`, and `canonical: true`.
Keep a short `Change Log` inside each file. Dated files are still fine for
one-off research notes, handoff briefs, or milestone archive snapshots.

`master-roadmap.md` is the implementation checklist that connects the release
product plan, current implementation state, QA backlog, and six-mode roadmap.
