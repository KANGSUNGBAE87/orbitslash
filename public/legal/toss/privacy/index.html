  • 선택한 토스 로그인: 일회성 인가 코드를 서버에서 인증서로 검증한 후 앱 전용 가명 식별값, 내부 계정 번호와 앱 세션을 처리합니다. 원래의 토스 식별키와 토스 접근·갱신 토큰은 지속 보관하지 않습니다. 토스 동의 화면의 필수 이름 항목은 응답받더라도 복호화·저장·공개하지 않습니다. 이메일·전화번호·생일·성별·CI는 요청하지 않습니다.
  • 로그인 사용자 기록 비교: 공개 닉네임(또는 임의의 Pilot 이름), 모드·난도·스토리 단계, 점수·생존 시간·처치·콤보, 시작·완료 시각을 저장합니다. 같은 조건의 순위·닉네임·점수·생존 시간은 로그인 참여자에게 표시됩니다. 비로그인 과거 기록을 자동 업로드하거나 다른 플랫폼 계정을 자동 병합하지 않습니다.
  • 자유방어 무료 시작 횟수와 광고 이용권·사용 이력: 비로그인은 기기, 로그인은 서버 계정 기준으로 관리합니다.
  • 광고 진단: 무작위 세션·시도 번호, 광고 종류·지면·그룹, SDK 사건, 오류, 보상·종료 상태, 시간 간격, 앱 버전과 테스트/실서비스 채널을 기록합니다. 실명·공개 닉네임·토스 식별키·광고/기기 식별자·전체 진입 URL은 넣지 않습니다. 토스·광고 사업자 자체 처리는 해당 정책과 동의 절차도 적용됩니다.
